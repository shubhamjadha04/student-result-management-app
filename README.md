# Student Result Management App

A simple **Student Result Management System** built using **Python**.

This project allows users to manage student information and check their academic results through a simple menu-driven application.

## 📌 Features

- Add new student records
- View all students
- Check a student's result
- Calculate total marks
- Calculate percentage
- Display pass/fail result
- Simple menu-driven interface
- Easy to understand Python code

## 🛠️ Technologies Used

- Python
- Python Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input
